# Начертательная геометрия — интерактивная карта к зачёту

Прямые, эпюр Монжа и метод прямоугольного треугольника — по шагам и простыми словами.

**Что внутри**
- Карта темы «что откуда берётся» и теория по лекциям 1–3 с 3D-моделями (крутятся пальцем).
- Лаборатория типов прямых и тренажёр «определи тип + опиши свойства» (задача 1 на зачёте).
- Метод прямоугольного треугольника: откуда он берётся, какой катет брать, пример по шагам (задача 2 и РЗ).
- Разбор всех вариантов ДЗ 1-01…1-16 (вариант 1-03 отмечен), обратные задачи с числом решений.
- Нарешка: задачи с пошаговым разбором, конструктор оформления «Дано / Алгоритм» с проверкой и объяснениями, генератор новых задач, пробный зачёт.
- Работает на телефоне, тёмная и светлая тема, прогресс сохраняется в браузере.

**Как открыть**
- Онлайн: включите GitHub Pages для ветки или откройте `index.html` через любой статический сервер.
- Оффлайн одним файлом: `nachertalka.html` (собирается командой `python3 tools/build.py`).

Всё написано на чистом HTML/CSS/JS без зависимостей; чертежи строятся кодом по координатам.
