# Полигон: бойцы «Дельта» / «Альфа»

Игра — `start.html` (THREE.js). Модели бойцов и окружение лежат в `assets/`.

## Как запустить
- С любого веб-сервера: `python3 -m http.server` в папке `game/`, затем
  открыть `http://localhost:8000/start.html`.
- Если открыть файл напрямую (`file://`), браузер запретит загрузку
  ассетов с диска, и игра возьмёт их с jsDelivr из ветки `main` репозитория.
  Если ассеты не загрузились, остаётся процедурная модель бойца.

## Бойцы
Реалистичная модель: тело MakeHuman с кожей на фото-текстурах, глаза с
роговицей, форма (китель, карго-брюки, заправленные в берцы), плитник,
перчатки, шлем FAST с наушниками, панама, балаклава. Сборка — скрипт
`tools/soldier/build.py` (Blender как Python-модуль), подробности в
`tools/soldier/README.md`. Модель привязана к скелету игры, поэтому IK рук и
хват оружия работают как раньше. Четыре бойца — одна геометрия; пресеты
`delta_1`, `delta_2`, `alpha_1`, `alpha_2` в `character.js` задают
камуфляж, цвета снаряжения, головной убор и балаклаву.

## Окружение
Туманный сосновый лес: HDRI-освещение, PBR-подстилка, стволы с корой,
пост-обработка (AO, цветокоррекция, виньетка, зерно). Ассеты —
`assets/env/` (скрипт `assets/env/build_env_assets.py`).

Лицензии: `assets/soldier/CREDITS.md`, `assets/env/CREDITS.md`.
Скриншоты — `screenshots/`.
