# Полигон: бойцы «Дельта» / «Альфа»

Вся игра — один файл `start.html` (THREE.js, без внешних моделей): открыть в браузере.

Боец собирается из частей тела в модуле `soldier.js` (внутри `start.html`):
туловище, руки, кисти с пятью пальцами по три фаланги, ноги, ботинки, голова.
Форма и снаряжение строятся от тех же поверхностей тела. Четыре бойца —
одна геометрия и один код; различаются только материалы (`character.js`,
пресеты `delta_1`, `delta_2`, `alpha_1`, `alpha_2`) и головной убор.

Скриншоты текущего состояния — в `screenshots/`.
