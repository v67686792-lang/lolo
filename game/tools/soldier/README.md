# Сборка реалистичного бойца

`build.py` собирает модель бойца для `game/start.html` и пишет её в
`game/assets/soldier/` (`soldier.json`, `soldier.bin`, `tex/`).

1. Тело: MakeHuman/MPFB2 — мужчина ~1,80 м, атлетичный; лицо на
   фото-текстурах кожи (+ щетина), глаза с роговицей, брови, ресницы.
2. Форма: рубашка-китель с карманами, карго-брюки (заправлены в берцы,
   с напуском), тактический жилет с подсумками, берцы, перчатки.
   Камуфляж накладывается в игре трипланарно, фактура вещи — из её текстуры.
3. Головные уборы (строятся по мешу головы): шлем FAST с рельсами,
   креплением ПНВ, липучками, противовесом и ремнём; активные наушники с
   микрофоном; панама; балаклава; короткая стрижка на коже головы;
   нашивка подразделения на груди.
4. Поза покоя — T-поза скелета игры (руки по ±X, ладони вниз), веса костей
   MakeHuman переносятся на кости игры: IK рук и хват оружия работают как
   раньше. Четыре бойца — одна геометрия, пресеты отличаются материалами,
   головным убором и балаклавой.

```sh
sudo apt-get install -y libsm6 libxext6 libxrender1 libxi6 libxkbcommon0 libxxf86vm1 libxfixes3 libgl1 libegl1
./fetch_assets.sh                      # MPFB2, паки MakeHuman, venv с bpy
SOLDIER_ART=$PWD/.cache .cache/venv/bin/python build.py ../../assets/soldier
```

Лицензии ассетов — `game/assets/soldier/CREDITS.md`.
